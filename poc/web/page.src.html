TaskJuggler in WebAssembly

The real TaskJuggler 3.8.4 scheduler, compiled to the browser with ruby.wasm. Edit the plan source and it reschedules here, with no server. Tap a task to change its effort from the chart; that edit is written back into the source.

Schedule

Starting Ruby and TaskJuggler in your browser. The first visit downloads about 9 MB, which a real app would cache for offline use.

Select a task to see its schedule and edit its effort.

Proof of concept. Scheduling is done by unmodified TaskJuggler sources (GPLv2, from github.com/taskjuggler/TaskJuggler) on CRuby 3.4 compiled to WebAssembly. Small shims replace the terminal-color gem and the network daemon library, route time zones through the browser's Intl data, reuse the grammar tables between runs, and re-implement a few core iterators to avoid ruby.wasm's slow stack-unwinding path. Results were checked against native TaskJuggler on its six bundled example projects.
